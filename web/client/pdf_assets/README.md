# PDF fonts

Unmodified Liberation Sans regular and bold fonts, vendored as base64 in fonts.ts for offline browser export. Source: the pdfjs-dist standard_fonts release bundled with the development runtime; upstream https://github.com/liberationfonts/liberation-fonts. SIL Open Font License 1.1 is reproduced in LICENSE_LIBERATION. Fonts are embedded and subset by jsPDF; no network font request occurs during export.
