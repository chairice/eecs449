# EECS 449 Project: An AI Agent for Everyday Tasks

A lot of daily life is made up of small, repetitive chores: sorting email, scheduling around conflicts, keeping track of deadlines, planning meals, remembering errands. None of them are hard. Together they take up a lot of time and attention.

This project builds a conversational AI agent that takes over some of that work. Instead of giving it step-by-step instructions, you describe what you want done, and the agent plans the steps, uses the right tools, and reports back.

## Goals

1. **Automate routine tasks.** Find everyday tasks that are repetitive and follow predictable rules, and let the agent handle them from start to finish.
2. **Keep it conversational.** Users should be able to talk to the agent in plain language, ask follow-up questions, and fix its mistakes without learning special commands.
3. **Use real tools.** Connect the agent to the services people already use (for example, calendar, email, to-do lists) so it can act, not just make suggestions.
4. **Keep the user in control.** The agent should ask before doing anything important or hard to undo, explain what it did, and respect the user's privacy.
5. **Measure the benefit.** Check whether the agent really saves time and effort compared with doing the same tasks by hand.

## Example Use Cases

- Summarizing and prioritizing an overflowing inbox
- Finding meeting times and managing calendar conflicts
- Tracking assignments, bills, and other deadlines, with reminders
- Planning errands, groceries, or weekly meals
- Drafting routine messages and replies
